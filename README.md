# Stoney-Updates

Offizielle Update- und Download-Dateien für **Stoney** – APK, Versionsprüfung und Website.

Dieses öffentliche Repository enthält **keinen Unity-Quellcode** des Spiels. Der eigentliche Stoney-Quellcode bleibt privat.

## Dateien

- `index.html` – öffentliche Download-/Update-Seite
- `version.json` – Versionsinformationen für den In-Game-Updater
- GitHub Releases – späterer Speicherort für signierte APK-Dateien
